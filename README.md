### 简介

Surfshark（中文也常被称为「鲨鱼 VPN」）是由荷兰阿姆斯特丹的 **Surfshark B.V.** 运营的 VPN 服务，自 2022 年起隶属于 Nord Security 集团。它最大的卖点是单个订阅**不限同时连接设备数**——这一点没有任何一家主流服务商能够对标——此外还拥有**分布在 100 个国家/地区的 4,500+ 台纯内存服务器**，并把杀毒、数据清除和身份保护工具打包进同一个套餐。

### 服务器网络

Surfshark 拥有**分布在 100 个国家/地区的 4,500+ 台服务器**——国家覆盖数量仅次于 Proton——并且整个服务器群均为**纯内存（RAM-only，无硬盘）**运行，每次重启都会清空，磁盘上不会留下任何数据。地区分布大致为欧洲 46 处、亚太 27 处、美洲 18 处、中东与非洲 9 处。**MultiHop** 可同时经由两个国家中转，**Dynamic MultiHop** 则允许自选两端节点。已获专利的 **Everlink** 技术可在服务器维护时把会话平滑迁移到新服务器，而不会直接断线。

### 功能特性

* **MultiHop** —— 同时经由两个国家中转；Dynamic MultiHop 可自选两端节点
* **NoBorders** —— 检测到受限网络时自动启用，切换到在审查环境下更可用的服务器列表
* **CleanWeb** —— 拦截广告、追踪器、恶意软件和 Cookie 弹窗
* **Bypasser** —— 分应用分流，支持按应用和按网址设置规则，并提供反向模式
* **终止开关（Kill switch）**、轮换 IP（Rotating IP）、独享 IP 与静态 IP 选项，以及保障会话稳定的 **Everlink**

支持协议：**Dausos**（Surfshark 自研，采用后量子加密）、WireGuard、OpenVPN 与 IKEv2（Windows 客户端已不再提供 IKEv2）。加密方式为 AES-256-GCM、ChaCha20 与 AEGIS-256X2。

### 速度、流媒体与 BT 下载

WireGuard 与 Dausos 是速度较快的选择，在独立测试中 Surfshark 长期位列最快的一档，应对 4K 播放与大文件下载绰绰有余。流媒体解锁依靠普通服务器而非专用服务器：评测普遍反馈可稳定访问美国、英国、日本等区域的 Netflix，以及 BBC iPlayer、Disney+、Hulu 和 Prime Video。**所有服务器均允许 P2P 流量**，BT 客户端会被自动路由，但 Surfshark 不提供端口转发。

Surfshark 注册于荷兰——属于欧盟、且在九眼联盟范围内，起点不如瑞士，公司以无硬盘服务器和审计记录来弥补这一点。**德勤（Deloitte）**分别在 2023 年和 2025 年验证了其无日志政策，**Cure53** 于 2026 年审计了其基础设施与新的 Dausos 协议，此前也审计过浏览器扩展。Surfshark 发布「预警信标（warrant canary）」及审计结果，详见 [surfshark.com/trust-center](https://surfshark.com/trust-center)。需要注意的是，与完全开源的竞品不同，Surfshark 仅部分代码开源。

### Surfshark 在中国大陆（连接不上怎么办）

如果 Surfshark 在防火长城下无法连接，请启用 **NoBorders** 模式——它会检测受限网络并切换到经过筛选的服务器列表，通常还会自动开启——并优选香港、日本或新加坡线路。Surfshark 未就中国大陆的可用性作出任何保证，2026 年的独立测试显示其在境内只能时断时续地使用，在敏感时期封锁会进一步收紧。建议出行前先安装并实测，并准备备用方案。参考：[surfshark.com/blog/vpn-china](https://surfshark.com/blog/vpn-china)。
